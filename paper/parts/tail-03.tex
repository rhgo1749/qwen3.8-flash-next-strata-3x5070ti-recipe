The PSS ablation is a single paired structural snapshot at reduced 32K context / 8K resident KV rather than the 262K / 32K serving configuration. Host-global swap use was retained (9.44 versus 5.70~GiB), but other system-wide memory counters and service-isolation provenance are insufficient to attribute the swap delta solely to the engines. CPU CCD/core-placement effects, DRAM bandwidth, PCIe-root contention, and thermal/power behavior are not independently decomposed. The 5070 Ti cards have a documented non-stock reference V/F profile, but its application at benchmark start was not snapshotted; the 5060 Ti tuning state is undocumented. The shared wrapper also rejects the upstream \texttt{MAP\_HUGETLB} attempt for the target arena and falls back to a regular file-backed mapping; we did not retain the host hugetlb-pool state, so page-size effects are another portability caveat.
